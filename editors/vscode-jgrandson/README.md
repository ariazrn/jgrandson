# JGrandson Language for VS Code

Adds `.jg` file recognition, a dedicated JG file icon, syntax highlighting,
comment commands, bracket matching, automatic closing, and indentation.

For local development, copy this directory into your VS Code extensions folder
as `jgrandson.jgrandson-language-0.1.0`, then restart VS Code:

- Windows: `%USERPROFILE%\.vscode\extensions`
- macOS/Linux: `~/.vscode/extensions`

The icon is a language-default icon. VS Code displays it when the active file
icon theme allows language icons and does not override the `.jg` extension.
