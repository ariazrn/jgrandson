# زبان برنامه‌نویسی JGrandson (جی‌گرندسان)
### مستند جامع مزیت‌ها، قابلیت‌ها و نوآوری‌های معماری

---

## ۱. معرفی (Overview)
**JGrandson** یک زبان برنامه‌نویسی مدرن، اعلامی (Declarative) و تمام‌عیار (Full-Stack) برای توسعه نرم‌افزارهای تحت وب است. این زبان به برنامه‌نویس اجازه می‌دهد تمامی اجزای یک رابط کاربری مدرن (طراحی، استیت، استایل و منطق تعاملی) به همراه سرویس‌های متصل به سرور و دیتابیس را در فایل‌های شفاف و خوانای `.jg` تعریف کند.

---

## ۲. مزیت‌های بنیادین (Core Advantages)

### ۱. حذف شلوغی‌های مرسوم فرانت‌اند (No Framework Boilerplate)
در فریم‌ورک‌های مرسوم وب (مثل React یا Vue)، توسعه‌دهنده ناچار است مفاهیم متعددی مثل هوک‌ها (`useState`, `useEffect`)، کدهای JSX/HTML، سیستم‌های استایل‌دهی جانبی و بسته‌بندها را ترکیب و مدیریت کند. در JGrandson:
* همه‌چیز در بلوک‌های تمیز مانند `page`، `component`، `state`، `style` و `slot` قرار دارد.
* نیازی به هوک‌های پیچیده یا کدهای تکراری نیست؛ استیت‌ها به شکل متغیرهای مستقیم مدیریت می‌شوند.

### ۲. کامپایلر دوگانه هوشمند (Dual-Target Compiler)
کامپایلر JGrandson انعطاف‌پذیری بی‌نظیری دارد:
* **تارگت نیتیو (Native Web - Zero JS):** برای صفحات ایستا (مانند مستندات و وبلاگ‌ها)، خروجی **دقیقاً ۰ بایت جاوااسکریپت** است و کدها مستقیماً به HTML5 و CSS خالص تبدیل می‌شوند. برای صفحات تعاملی، بدون نیاز به Virtual DOM سنگین، تغییرات مستقیماً به گره‌های DOM اعمال می‌شوند.
* **تارگت ری‌اکت (React Target):** قابلیت کامپایل به **React + TypeScript (TSX)** برای بهره‌گیری از کل اکوسیستم کتابخانه‌ها و پکیج‌های موجود در دنیای React در قالب «جزایر سازگاری» (Compatibility Islands).

### ۳. امنیت قطعی در زمان کامپایل (Compile-Time Security & Boundaries)
یکی از چالش‌های بزرگ برنامه‌نویسی وب، نشت تصادفی اطلاعات محرمانه (API Keyها و کدهای دیتابیس) به باندل مرورگر است.
* کامپایلر JGrandson تفکیک سخت‌گیرانه‌ای میان ماژول‌های `browser`، `server` و `shared` اعمال می‌کند.
* اگر کدی در مرورگر بخواهد به متغیرهای محرمانه یا پایگاه داده سرور دسترسی پیدا کند، پروژه **در زمان کامپایل** خطا می‌دهد و متوقف می‌شود.

### ۴. لایه هوش مصنوعی بومی و تایپ‌شده (AI as a Typed Capability)
هوش مصنوعی در JGrandson صرفاً یک API خارجی نیست:
* **تفکیک پیشنهاد از اجرا:** هوش مصنوعی فقط می‌تواند تغییرات را «پیشنهاد» (Propose) دهد؛ اجرای تغییرات حساس نیازمند تاییدیه و قوانین امنیتی سرور است.
* **تست‌های قطعی (Deterministic Mocks):** قابلیت اجرای تست‌های واحد هوش مصنوعی بدون نیاز به شبکه و صرف هزینه.
* **کنترل بودجه و هزینه:** امکان محدودسازی تعداد توکن‌ها و درخواست‌ها برای هر کاربر.

### ۵. رهگیری اصالت داده و اعتماد (Data Provenance & Trust Types)
کامپایلر منشأ داده‌ها را ردیابی می‌کند:
* داده از کجا آمده است؟ (`user`، `database`، `cache`، `ai`).
* آیا مورد اعتماد است؟ (`untrusted`, `validated`, `authorized`).
* **نتیجه:** جلوگیری سیستمی از ارسال داده‌های تاییدنشده یا قیمت‌های منقضی‌شده به پردازش‌های حساس مالی و تجاری.

## ۳. جدول مقایسه JGrandson با ابزارهای رایج

| ویژگی / قابلیت | JGrandson (`.jg`) | React / Next.js | Svelte |
| :--- | :---: | :---: | :---: |
| **تعریف UI در یک فایل تمیز** | ✅ بومی و یکپارچه | ❌ نیازمند JSX + CSS + Hooks | ✅ با سینتکس اختصاصی |
| **خروجی صفحات ایستا بدون جاوااسکریپت** | ✅ خودکار (Zero JS) | ⚠️ نیازمند SSR/SSG و هیدریشن | ⚠️ نیازمند تنظیمات خاص |
| **مرزبندی امنیتی سرور/کلاینت در کامپایلر** | ✅ تضمین شده در سطح زبان | ⚠️ در ران‌تایم و فریم‌ورک | ❌ وابسته به سرور |
| **پایگاه‌داده و مایگریشن توکار** | ✅ دارد (`SQLite` / `Postgres`) | ❌ نیازمند ORMهای جداگانه | ❌ ندارد |
| **تولید خودکار کلاینت و OpenAPI** | ✅ دارد | ⚠️ نیازمند ابزارهای جانبی (tRPC) | ❌ ندارد |
| **هوش مصنوعی به عنوان قابلیت تایپ‌شده** | ✅ ساختاریافته در زبان | ❌ فقط پکیج‌های خارجی | ❌ فقط پکیج‌های خارجی |

## ۴. اجزای اصلی اکوسیستم پروژه

```text
jgrandson/
├── packages/
│   ├── ast/             # ساختار گره‌های زبان و سیستم گزارش خطا
│   ├── lexer/           # توکنایزر و تحلیل ساختاری
│   ├── parser/          # تبدیل کدهای سورس به درخت گرامر (AST)
│   ├── analyzer/        # تحلیل معنایی، اصالت داده و کنترل بودجه
│   ├── compiler/        # کامپایلر React و Native
│   ├── runtime/         # سرور Express، دیتابیس (SQLite/PG) و هوش مصنوعی
│   ├── cli/             # دستورات ترمینال (jg dev, jg build, jg check, ...)
│   └── language-server/ # سرور هوشمند LSP برای ویرایشگرهای کد
```

## ۵. نمونه کدهای شاخص

### کامپوننت تعاملی فرانت‌اند (`Counter.jg`)
```jg
page CounterApp {
  state {
    count: number = 0
  }

  style {
    padding: 24
    backgroundColor: "#fafafa"
  }

  main {
    h1 { text { content: "شمارنده هوشمند" } }
    p { text { content: "تعداد کلیک: " + count } }

    button {
      text: "افزایش"
      onClick {
        count = count + 1
      }
    }
  }
}
```

### روت سرور با پایگاه داده و کنترل دسترسی
```jg
route GET "/api/users" {
  let db = new SQLiteAdapter("app.db")
  let users = await db.query("SELECT id, name, email FROM users")
  return users
}
```

## ۶. جعبه ابزار توسعه‌دهنده (Developer Experience)
* **`jg dev`**: اجرای محیط توسعه زنده با پشتیبانی از سرور فوق‌سریع Vite و بارگذاری آنی تغییرات (HMR).
* **`jg build --target=native`**: خروجی مستقیم HTML5 و CSS بهینه بدون نیاز به فریم‌ورک‌های حجیم.
* **`jg check` / `jg lint`**: تحلیل عمیق معنایی، بررسی دسترسی‌پذیری وب (A11y) و استانداردهای کد.
* **اکستنشن VS Code**: آیکون اختصاصی، تمیزکاری کد، تکمیل خودکار و بررسی لحظه‌ای خطاها.
