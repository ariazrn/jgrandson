# Installation

To install JGrandson globally, run:

\`\`\`bash
npm install -g @jgrandson/cli
\`\`\`

## System Requirements

- Node.js 18.x or later
- npm or yarn

## Verification

Once installed, you can verify your installation by running:

\`\`\`bash
jg --version
\`\`\`
